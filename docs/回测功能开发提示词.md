# HermesX 回测功能开发提示词

> 用途：交给 AI / 开发执行「新增回测能力」时的完整需求说明  
> 含：网格搜索、手续费、滑点、样本外验证

---

【角色定位】：你是一名资深的全栈量化交易系统开发工程师，拥有大量加密货币永续合约、策略回测与 NestJS/React 领域的开发经验，代码规范、注释完整、兼容性强。

【需求背景】：我需要在现有 HermesX（数字货币 USDT 永续合约周期对冲交易系统）项目上新增「回测功能」。用于在实盘/模拟盘下单前，用历史 K 线验证「按周期同时开多+开空 + 独立 TP/SL（平仓量精确等于 Q）」策略的有效性；并支持**参数网格搜索**、**手续费**、**滑点**与**样本外验证**，解决参数难系统评估、忽略交易成本/成交偏差导致收益虚高、以及样本内过拟合的问题。

【核心目标】：
1. 实现回测引擎：按策略参数在选定交易对、时间区间、周期（1m/3m/5m/15m/1h/4h/1d）上重放历史行情，模拟每周期双边开仓，并按精确数量 Q 触发 TP/SL。
2. **手续费计入 PnL**：支持可配置费率（至少开仓/平仓；可用 Maker/Taker 或统一费率）；统计与明细均为**扣费后**结果。
3. **滑点建模**：支持可配置滑点（至少支持按成交名义金额的百分比，如 0.02%；可选固定点数）；开仓/平仓/TP/SL 成交价按不利方向偏移后再计盈亏；明细中记录假设价、滑点后成交价与滑点成本。
4. **参数网格搜索**：对关键参数设定候选列表（至少：`cycleInterval`、`takeProfitPct`、`stopLossPct`、`leverage`、`quantity`），穷举组合批量回测；输出对比表（扣费+滑点后的总盈亏、胜率、最大回撤、盈亏比、交易次数、总手续费、总滑点成本），并标出按指定目标排序的 Top N。
5. **样本内外验证**：支持将回测区间拆为「样本内（In-Sample）」与「样本外（Out-of-Sample）」两段（可配置切分比例，如 70%/30%，或按起止日期手动指定）。网格搜索**仅在样本内**调参；选定最优（或 Top N）参数后，在样本外用**相同参数再跑一次**并输出对比（样本内 vs 样本外）。前端需同时展示两段结果，避免只展示样本内最优造成误导。
6. 与现有系统一致：策略参数对齐现有 Strategy；回测/网格与实盘下单路径严格隔离。

【输出规范】：
1. 代码使用 TypeScript；后端 NestJS 10 + Prisma/PostgreSQL，前端 React 18 + Vite + Tailwind；与现有 npm workspaces（`backend` / `frontend`）一致。
2. 代码必须添加完整的中文注释。
3. 按模块拆分并标注文件名称与作用（建议至少：回测引擎、手续费计算器、滑点计算器、网格搜索调度、样本切分与样本外复跑、历史行情拉取/缓存、任务 API、Prisma 模型与迁移、前端回测页/网格对比/样本内外对比）。
4. 提供完整运行步骤与依赖说明（含：单次回测、带手续费+滑点、网格搜索、样本内外验证的示例操作路径）。

【约束条件】：
1. 不得引入与现有栈不兼容的依赖（优先复用 ccxt、Prisma、现有 UI）。
2. 必须适配现有 HermesX 环境（Docker Compose / 开发与生产部署）。
3. 代码必须可直接运行；回测/网格**不得**调用真实下单接口。
4. 不得出现安全漏洞（JWT；输入校验；限制时间跨度、K 线数量、网格组合上限；超限明确报错）。
5. 手续费、滑点默认值需合理并在文档说明（如默认 Taker 费率 + 默认滑点 bps）；关闭滑点/手续费时应可对比「理想成交」与「扣成本后」结果。
6. 网格搜索禁止用全区间成绩直接当最终结论：启用样本外验证时，必须以样本外（或样本内+样本外并列）作为验收展示；若用户关闭样本外验证，界面需提示过拟合风险。

【验收标准】：
1. **单次回测**：BTCUSDT、固定区间与参数跑通，产出扣费+滑点后的统计与明细，全程无真实下单。
2. **手续费**：同行情同参数下，有手续费时总盈亏 ≤ 零费率时总盈亏；明细手续费合计与统计一致。
3. **滑点**：同行情同参数下，有滑点时总盈亏 ≤ 零滑点时总盈亏；明细中成交价相对触发价按不利方向偏移。
4. **网格搜索**：至少 2×2（如 TP%×SL%）生成对比表，可按扣成本后总盈亏排序看到最优组合；组合超上限行为符合约束。
5. **样本外验证**：同一任务在样本内网格选出最优参数后，样本外自动复跑；页面可见两段指标对比；两次相同配置运行结果可复现。
6. **一致性**：相同行情数据、参数、费率、滑点、切分方式，重复运行统计一致。
